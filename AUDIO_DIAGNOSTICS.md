# Журнал діагностики та Стандарти Аудіо School Bell

Цей документ містить технічні вимоги до аудіофайлів для забезпечення 100% стабільності відтворення в системі School Bell.

---

## ✅ Рекомендований стандарт (Гарантоване відтворення)
Для надійної роботи системи рекомендується використовувати файли з наступними параметрами:

1.  **Формати файлів**: 
    *   **MP3** (MPEG-1 Layer 3) — найбільш рекомендований.
    *   **WAV** (PCM) — ідеальний для сигналів тривоги (найшвидший старт).
    *   **M4A / AAC** (з профілем LC) — сучасний стандарт високої якості.
2.  **Профіль AAC**: Тільки **AAC-LC** (Low Complexity).
3.  **Частота дискретизації**: **44100 Hz** (44.1 кГц) або **48000 Hz** (48 кГц).
4.  **Бітрейт**: До 320 kbps (бажано Constant Bit Rate - CBR).
5.  **Канали**: **Stereo** (2 канали) або **Mono** (1 канал).

---

## ⚠️ Складні кейси (Можуть бути пропущені системою)
Наступні типи файлів можуть призводити до помилок декодування через обмеження Java Sound API:

1.  **Непідтримувані профілі AAC**:
    *   **AAC SSR** (Scalable Sample Rate) — застарілий рідкісний профіль.
    *   **HE-AAC** (High-Efficiency) — іноді може розпізнаватися як шум або мати помилки швидкості.
2.  **Екстремальні параметри**:
    *   Частота понад 48000 Hz (напр. 96 кГц або 192 кГц).
    *   Багатоканальний звук (5.1, 7.1 Surround).
3.  **Проблеми з метаданими**:
    *   **Дуже великі обкладинки альбомів**: Якщо в файл вшито зображення роздільною здатністю 4K або розміром понад 2-3 МБ.
    *   **Подвійні заголовки**: Коли файл містить декілька блоків ID3-тегів поспіль.
4.  **Маскування форматів**:
    *   Файли **AAC/M4A**, яким вручну змінили розширення на `.mp3`. Система намагається їх відновити, але це не завжди можливо.
5.  **Захист (DRM)**:
    *   Файли, завантажені з підписок (Apple Music, Spotify), які мають захист від копіювання.

---

## 🛠 Поради щодо виправлення проблемних файлів
Якщо важливий для вас трек не відтворюється:
1.  **Переконвертуйте файл** у стандартний MP3 (128-320 kbps, 44.1 kHz) за допомогою будь-якого конвертера або програми Audacity.
2.  **Очистіть теги**: Видаліть гігантські обкладинки альбомів за допомогою утиліти **Mp3Tag**.
3.  **Перевірте розширення**: Переконайтеся, що файл не є перейменованим відео-файлом або іншим типом даних.
