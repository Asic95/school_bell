# Ідеї для нових медіа-тригерів

## Контекст

Є запит зробити запуск аудіо перед уроками більш надійним і зручним.

Поточний сценарій з фіксованим часом, наприклад `08:00`, має проблему: якщо комп'ютер увімкнули пізніше, наприклад о `08:02`, подія вже пропущена і музика перед уроками не стартує.

Також є окремий запит: деякі вчителі хочуть аудіосповіщення перед першим уроком замість попереднього дзвінка. Перший урок може починатися не завжди о `08:30`; іноді це може бути `10:00` або інший час за розкладом.

## Ідея 1: Тригер "У проміжку часу"

### Призначення

Для ранкової або іншої фонової музики, яка має грати в певному часовому вікні, навіть якщо програму запустили із запізненням.

### Приклад

Ранкова музика:

- початок: `08:00`;
- кінець: `08:25`;
- дні: понеділок-п'ятниця;
- джерело: папка з музикою або радіо;
- якщо програму запустили о `08:02`, музика стартує автоматично;
- якщо програму запустили о `10:15`, музика не стартує.

### Поля в UI

- `Тип тригера`: `У проміжку часу`;
- `Початок`;
- `Кінець`;
- `Дні тижня`;
- `Джерело аудіо`: файл / папка / радіо;
- `Запускати при старті програми, якщо зараз цей проміжок`;
- `Затримка після старту програми`, наприклад `10 секунд`;
- `Зупинити перед найближчим дзвінком`.

### Поведінка

Якщо програма стартує всередині проміжку, аудіо запускається після короткої затримки.

Затримка потрібна, щоб програма встигла:

- завантажити конфігурацію;
- перевірити розклад;
- перевірити реле;
- перевірити стан тривоги/НС;
- не стартувати аудіо занадто рано під час запуску застосунку.

### Обмеження

Не запускати аудіо, якщо:

- активна повітряна тривога;
- активна надзвичайна ситуація;
- уже грає інше пріоритетніше аудіо;
- поточний час уже поза межами проміжку;
- сьогодні не вибраний день тижня.

## Ідея 2: Тригер "Перед першим уроком"

### Призначення

Для короткого аудіосповіщення перед початком першого уроку, яке не прив'язане до фіксованого часу.

Це корисно, якщо перший урок у різні дні або за різними розкладами починається в різний час.

### Приклад

Налаштування:

- тип: `Перед першим уроком`;
- зміщення: `5 хвилин`;
- джерело: аудіофайл зі сповіщенням.

Поведінка:

- якщо перший урок о `08:30`, аудіо стартує о `08:25`;
- якщо перший урок о `10:00`, аудіо стартує о `09:55`.

### Поля в UI

- `Тип тригера`: `Перед першим уроком`;
- `За скільки до першого уроку`: хвилини/секунди;
- `Дні тижня`;
- `Джерело аудіо`: файл / папка / радіо;
- `Запустити навіть якщо програма стартувала із запізненням`;
- `Допустиме запізнення`, наприклад `2-5 хвилин`.

### Поведінка

Програма:

1. Бере розклад на поточний день.
2. Знаходить перший запис типу `початок уроку`.
3. Віднімає задане зміщення.
4. Запускає аудіо у розрахований час.

Якщо програма стартувала після розрахованого часу, можна дозволити запуск у межах допустимого запізнення.

Приклад:

- перший урок о `10:00`;
- сповіщення за `5 хвилин`;
- плановий запуск о `09:55`;
- комп'ютер увімкнули о `09:56`;
- допустиме запізнення `3 хвилини`;
- аудіо все ще запускається.

Але якщо комп'ютер увімкнули о `10:10`, аудіо вже не запускається.

## Рекомендований поділ сценаріїв

Краще не змішувати ранкову музику і попереднє сповіщення перед уроком в один тип.

Рекомендовано мати два окремі типи:

- `У проміжку часу` - для фонової музики перед уроками або в інші періоди.
- `Перед першим уроком` - для короткого аудіосповіщення, яке залежить від розкладу.

Так UI буде зрозуміліший, а логіка менш ризикована.

## Пріоритети

Першим варто реалізувати `Перед першим уроком`, якщо головний запит від школи - замінити попередній дзвінок аудіосповіщенням.

Другим варто реалізувати `У проміжку часу`, якщо головний запит - ранкова музика, яка має стартувати навіть після пізнього запуску комп'ютера.

## Важливі правила

- Не запускати медіа під час повітряної тривоги або НС.
- Не запускати медіа поверх активного сигналу реле.
- Не запускати одну й ту саму подію багато разів у межах одного дня.
- Якщо аудіо вже грає, використовувати існуючу логіку fade/transition, крім сценаріїв тривоги/НС.
- Для подій, які залежать від розкладу, враховувати фактичний розклад поточного дня, а не фіксований час.
